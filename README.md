# Audex Trace

Audex Trace is a menu bar companion for Apple Music on macOS. It shows the codec, bit depth, and sample rate of the track that is playing, whether the output device's format matches it, and upcoming tracks in Playing Next.

## Download

Download from the [Releases page](https://github.com/audexdev/trace-releases/releases) of this repository, or visit [trace.audex.dev](https://trace.audex.dev).

## Requirements

- macOS 15 or later
- Apple Music (Music.app) playback
- A macOS administrator account (required for playback-format detection, because standard accounts cannot read playback logs)

The app is signed with a Developer ID and notarized by Apple. No logging configuration profile is needed.

## Free and Pro

- **Free (no time limit)**: Now Playing with playback controls, Playing Next, and Playback Verification to check whether playback-format detection works with your output device before buying.
- **Pro ($29.99, one-time purchase, lifetime license)**: Adds playback readout, output match status, queue quality estimates, skip warnings, and Auto Sample Rate Match to set the output device's sample rate to match the playing track.
